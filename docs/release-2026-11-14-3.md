# EMCIA Gestion — 2026.11.14.3

Daily operations now includes “متابعة أداء متعلمي اليوم” / “Suivi des paiements des apprenants du jour”.

- One row per learner, ordered by first scheduled monthly lesson on the selected date. Active learners, groups and monthly enrollments are required. Session-billed enrollments are excluded.
- Only dues for the learner's groups programmed on that date are included. Dues use the existing monthly/discount/accounting-start rules and the actual due date (enrollment start for the first month, first day for later months).
- Payments use their month allocations, including composite receipts, and account for refunds. Paid-up learners disappear; partial payments update the remaining balance on save.
- Filters cover group, unpaid/partial/previous months, and recorded presence in scheduled monthly lessons. The learner is not duplicated across groups or lessons.
- Payment actions open the monthly payment screen with the chosen group and learner selected.
- Staff manually document a reminder using “تم التذكير”. This records a reminder; it does not send a message or alter the debt.
- Reminder records are stored independently of the large operational JSON. A database primary key enforces one record per learner/date across staff. Staff identity/name and time are validated/recorded on the server; anonymous access, spoofed actor names and non-current dates are rejected. The first reminder remains authoritative on duplicate clicks.
- Reminder records refresh while daily operations is open. Network errors show a retry message, never a success state. Historical/future dates can be reviewed; recording is limited to the current Casablanca date.
- Arabic and French labels are provided.

Validation: synthetic DOM/auth/sync tests cover timetable eligibility, learner deduplication, first lesson ordering, first-month future enrollment, session exclusion, composite payments, filtering, recorded presence, the generated payment action, reminder idempotence, and automatic disappearance after payment. Database role tests passed for director, accountant and both secretary roles, including actor attribution, duplicate protection, spoof rejection and date checks. Database tests ended in rollback; no test reminders remain.

The existing attendance, accounting and transactional-save regression tests also passed. Real-device visual acceptance remains separate from these automated checks.
