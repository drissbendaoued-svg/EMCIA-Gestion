# Release 2026.11.17.1

Add name and group filters above the learner selector in Learner File, with a matching-result count and clear-filters button. Partial Arabic/French stored names can be searched with multiple words. Name/group criteria combine, the selector updates without replacing the typing field, and criteria persist when opening a file. No match clears the previous profile to avoid showing a file outside the search. No learner is automatically selected.

Group matching includes historical enrollments so archived/stopped learners remain searchable; duplicate enrollments do not duplicate candidate learners. The filter selects files and does not scope or change a selected learner's financial/history data.

Validation: full application JavaScript compiled for syntax in the hosted runtime. A new standalone student-file-search test was executed against final source in the hosted runtime, covering bilingual partial names, combined criteria, historical membership, deduplication, no results, preserved input nodes, retained filters on file selection, stale-profile clearing, safe initial rendering and inline-handler syntax. Added to npm test. Full DOM/auth suite was not rerun because the executor was unavailable. No production records were modified.
