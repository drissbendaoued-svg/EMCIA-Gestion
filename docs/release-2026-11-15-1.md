# Release 2026.11.15.1

Fix monthly payment form collapsing into a single narrow column after learner selection.

The payment area now spans all parent columns and uses its own responsive grid: two columns on phones and three on larger screens. Both initial rendering and learner-change handlers preserve this layout. Settlement, composite distribution and the save button span the full form width. Shared-receipt guidance is collapsed by default; field labels and financial behavior are preserved.

Validation: full mocked DOM/auth/cloud integration suite, including a regression check that dispatches the actual learner-change event, toggles monthly/session modes and verifies the full-span grid survives. Existing financial, settlement and study-stop checks pass. No production financial records were changed.
