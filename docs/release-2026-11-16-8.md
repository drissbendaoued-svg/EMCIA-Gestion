# Release 2026.11.16.8

Timetable editing now includes a numbered room choice with room names/capacities and the existing room selected by default. Active rooms are offered; an inactive current room remains available only as the existing choice. A new room is included in the same candidate as the day, times and session type, and the existing conflict validator runs before any mutation. Moving into an undersized room requires explicit confirmation. Cancellation, invalid choice or conflict leave the schedule row untouched.

The existing lesson ID is retained, preserving attendance references. No lesson deletion/recreation or production record changes were performed.

Validation: full application JavaScript compiled for syntax in the hosted runtime. New standalone schedule-room tests executed against final source using hosted JavaScript, covering a free room move, occupied room rejection, teacher conflict in another room, cancellation rollback, invalid choice, capacity confirmation, stable schedule ID and attendance references. Test added to npm test; the existing DOM edit fixture was updated for the new room prompt. Full DOM suite was not rerun because the executor was unavailable.
