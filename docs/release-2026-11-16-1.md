# Release 2026.11.16.1

Additional income entry now accepts a populated category/amount directly through Save, while preserving multi-item batches. Decimal amounts are supported and non-positive/non-finite amounts and invalid dates are rejected. The saved-income table displays receipt numbers and an explicit total covering all recorded months.

Editing an income date updates its accounting month in the same operation. Monthly financial and comprehensive reports now include legacy month-only income, expense and saving records, using the same accounting-month rule as dashboard totals.

Validation: full synthetic DOM/auth/cloud suite passes. Added tests exercise actual add/save buttons, decimal batches, lower-table receipt/total display, budget and report inclusion, financial-state serialization, accountant reload, date/amount edits, rejected invalid input, deletion and director reload. Existing payment, session, attendance, settlement, study-stop and sync conflict checks remain passing. All API calls in the suite are mocked; no production financial records or database schema were changed. Production verification checks the published release bytes.
